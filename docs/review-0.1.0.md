# 0.1.0 리뷰·검증

## Why

사용자의 최소 health 목표를 실제로 구현했는지와 요청 범위를 넘지 않았는지 판단한다.

## What

- Claude Opus: 최소 Hono 서버·PM2 설정 초안 작성.
- GPT Sol: 소스와 설정 리뷰, 의존성 설치·실행, PM2 재시작·공개 Funnel 경로 검증, GitHub 이슈·브랜치 보호 반영.
- Gemini Flash(gf): 소스·설정 분리·dev 소스 게이트와 최신 지침의 독립 최소 리뷰. 명백한 차단성 결함 없음으로 판정.
- 작성 모델과 다른 계열 리뷰를 적용했고 재귀 리뷰는 추가하지 않았다. 각 모델 결과는 실제 파일·응답으로 대조했다.

## How

- Node 문법 확인과 코드 모듈별 128줄·1024자 한도 검증 통과.
- 로컬 health HTTP200, PM2 biseo 재시작 후 HTTP200 통과.
- Funnel의 공개 글로벌 IP를 직접 경유한 TLS 요청에서 무인증 HTTP200과 최소 JSON 응답 통과.
- dev 소스 게이트의 로컬 양·부정 사례: 같은 저장소 dev 통과, 다른 브랜치 및 다른 저장소 dev 거부.
- 인증·키 관리·워커 API·부하/장애 실험은 현재 구현 범위에서 제외했다.
- main PR의 필수 검사는 실제 GitHub PR에서 별도로 확인한다. PR 생성은 main merge와 같지 않다.
