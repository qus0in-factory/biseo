# v0.6.3 릴리스 노트 (초안)

v0.6.2 태그 이후 준비 기준 `865a89a`까지 병합 2건과 일반 커밋 3건을 대조했다. 근거 명령은 `git log --merges v0.6.2..HEAD`와 `git log --no-merges v0.6.2..HEAD`다. PR 번호가 없는 변경은 커밋으로 표시한다. 이 릴리스 준비 커밋은 버전·문서만 바꾼다.

## 변경

- AGY CLI 폴백 기본 인수를 `-p /quota`로 바꿨다. 기존 TSV 파서로 Argon 주간 행을 처리하며 파서를 교체하지 않았다. (`0cb5164`, 병합 `865a89a`)
- 폴백은 기본 켜짐이며 `BISEO_AGY_CLI_ENABLED=0`일 때만 꺼진다. 미설정과 그 밖의 값은 켜짐이다. v0.6.2의 기본 꺼짐·`1`일 때만 켜짐과 구분한다. (병합 `865a89a`)
- `BISEO_AGY_CLI_MIN_INTERVAL_MS`의 기본값과 하한은 600000ms(10분)이다. 더 작은 값은 10분으로 올리며, `BISEO_AGY_CLI_CACHE_MS`가 더 크면 그 값까지 성공·실패 결과를 재사용한다. 프로세스 내부 간격이며 비용 상한이나 프로세스 간 제한은 아니다. (`f6c6ccd`에서 도입, 병합 `865a89a`에서 10분으로 조정)
- 겹친 폴백 요청은 진행 중인 CLI 호출을 공유한다. (`93046a4`)
- v0.6.1에서 `/usage`가 유료 모델 턴을 일으킨다고 단정한 전제를 정정한다([#237](https://github.com/qus0in-factory/biseo/issues/237#issuecomment-6703912448)). astra는 2026-11-07 agy 1.5.2에서 `agy -p /quota`와 `agy -p /usage`를 각각 1회 실행했다. 추가된 CLI 로그의 `generateContent`·`streamGenerateContent`는 모두 0회였고, 두 명령은 종료 코드 0과 Argon 주간 행을 반환했다. 소요 시간은 각각 5.365초·5.237초였다. 이는 해당 버전·계정·인수의 로그 기반 모델 턴 0 실측이며 전체 TLS 계측이나 다른 버전·사용자 지정 인수의 보장은 아니다. (`0cb5164`)
- v0.6.2 노트에 잘못 들어간 기본 켜짐 설명을 당시 코드 범위로 되돌렸다. 운영 문서는 `unknown` 상태와 `agy_auth_expired` reason에 따른 인증 필요 분류를 구분했다. 이 정정은 런타임 동작을 바꾸지 않는다. (이번 준비 커밋, grok 리뷰 P2-1·P2-2)

## 로컬 검증

- 테스트 1031/1031·27 suites, 실패·취소·skip·todo 0이다.
- 전체 타입 검사와 서버·클라이언트 빌드를 통과했다. 클라이언트 빌드에는 500 kB 초과 청크 경고가 있다.

## 발행·운영 범위

이 노트는 로컬 릴리스 준비 기록이다. main 병합·push·태그·정식 릴리스 발행·배포·재시작은 포함하지 않는다. 체크리스트의 배포와 운영 버전 대조는 이번 승인 범위 밖이라 실행하지 않았다. 운영 화면 버전·Argon 주간 표시·인증된 사용량 회복은 확인하지 않았으며, 위 astra 실측도 이번 작업에서 재실행하지 않았다.
