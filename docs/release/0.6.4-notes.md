# v0.6.4 릴리스 노트 (초안)

v0.6.3 태그 이후 준비 기준 `25c6d70`까지 병합 2건과 일반 커밋 4건을 대조했다. 근거 명령은 `git log --merges v0.6.3..HEAD`와 `git log --no-merges v0.6.3..HEAD`다. PR 번호가 없는 변경은 커밋으로 표시한다. 이번 준비 커밋은 버전·문서만 바꾼다.

## 변경

- Grok 기간 매핑을 `Map`으로 바꿔 `constructor`·`toString` 같은 상속 키가 기간으로 선택되지 않게 했다. 주간·월간 매핑과 그 밖의 값에 대한 `primary` 기본값은 유지한다. (`55df2cc`)
- Claude 설정 읽기 실패 시 기본값을 복사해 반환해 호출 간 공유 참조를 제거했다. 설정 수치와 백오프 시각에 ECMAScript Date 범위 가드를 적용해 극단값에 따른 잘못된 날짜 변환을 막았다. (`55df2cc`)
- provider policy JSON을 로드할 때 런타임 검증한다. 객체가 아닌 항목은 제외하고 `staleReasons`는 문자열만 남긴다. 잘못된 `restoreState`는 기존 상태 결정 로직으로 처리한다. (`973f695`)
- policy 저장소에 null prototype을 쓰고 두 조회 경로에서 own key만 허용한다. 상속 키는 정책으로 조회되지 않으며 명시한 `__proto__`도 일반 own key로만 저장된다. (`25c6d70`)
- net guard 테스트 이름에 전송 방식별 호출식을 넣어 구분하고, 자식 프로세스에 5000ms timeout을 적용했다. (`1c5f621`)

정상 입력·현재 정책 설정에서 사용자 동작 변화는 없다. 잘못된 입력·상속 키·극단적인 날짜 값에 대한 방어와 테스트 진단을 보강한 릴리스이며, 새 사용자 기능이나 운영 설정 변경은 포함하지 않는다.

## 로컬 검증

- 테스트 1037/1037·27 suites, 실패·취소·skip·todo 0이다.
- 서버·클라이언트 빌드를 통과했다. 클라이언트 빌드에는 500 kB 초과 청크 경고가 있다.
- `package.json`은 `0.6.4`이며 README·개발·현행 운영 문서의 준비 기준도 일치한다. 로컬 클라이언트 번들의 앱 버전 표식 `app-version:0.6.4`도 대조했다. 운영 버전 확인 결과는 아니다.

## 발행·운영 범위

이 노트는 로컬 릴리스 준비 기록이다. main 병합·push·태그·정식 릴리스 발행·배포·재시작은 포함하지 않는다. 체크리스트의 배포와 운영 버전 대조는 이번 승인 범위 밖이라 실행하지 않았다. 운영 화면 버전·Argon 주간 표시·인증된 사용량 회복은 확인하지 않았다.
