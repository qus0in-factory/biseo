## 0.3.0 계약(포함)
- 기존 최소 SSE, 보안(인증·CSRF·XSS·대상 제한), 완료 응답 수집
- turn_timeout 후 late 수집(timeout→completed만 허용)
- 연결 안정화: [connection-stability-0.3.0.md](../ops/connection-stability-0.3.0.md)
- 기본 iOS 대응, 우선 입력 수정: busy일 때 전송만 차단, input 편집 가능, textarea `resize:none`
- glm-z `hi` 기록은 `idle interrupted`·assistant aborted로 완료 응답 없음. 중단의 원인은 미확정이며 자동 재전송하지 않는다. 배포본은 `--wait` 후 3초 수집 결과 null을 수집 불가로 처리했다. 새 대기 경로에서 같은 기록은 timeout, 3.2초 지연 응답은 completed로 확인(ds-g 재생 검증; 새 실제 패널 전송 없음).

- sol 실행: Node 24.22.1, 최종 타입 검사·전체 빌드 통과. 후속 초안 제거·pacing 수정 및 web/app 회귀 포함 후 기본 `pnpm test` 147건 통과.

- main 보호: PR 필수·관리자 적용·필수 main-source 검사·강제 push/삭제 금지 유지.
- settled-null late reader의 다음 읽기는 기존 chunk·남은 시간에 맞춰 기다린다. ds-g 재생에서 200ms당 5435회였던 반복이 2회로 감소했고, 호출 상한·세대 변경 중단 회귀 테스트를 sol 전체 검증에 포함했다.
