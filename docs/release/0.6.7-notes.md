# v0.6.7 릴리스 노트 (초안)

## 운영 전환 주의사항

**배포 전에 저장소 밖의 보호 env 파일을 준비해야 한다.** 운영값을 공유 설정에서 분리했으므로 기존 설정 파일만 믿고 pull·재시작하지 않는다. `BISEO_ENV_FILE`로 경로를 지정하며 기본값은 `${XDG_CONFIG_HOME:-$HOME/.config}/biseo/biseo.env`다. 파일 값은 같은 이름의 프로세스 env보다 우선한다. 파일이 없으면 기존 env로 진행하지만 필수 키가 없으면 부팅이 실패한다. 파일·상위 디렉터리 권한은 각각 `600`·`700`으로 제한한다. 값은 로그·문서·커밋에 남기지 않는다. [전환 절차](../ops/runtime-config.md)에 따라 보호 파일과 기존 상태 파일을 보존한다. (`334f4f9`, `d6cb5fc`)

사용량 이력 테이블 삭제 마이그레이션 `0013_drop_usage_history.sql`은 원격 D1에 별도 적용해야 한다. `usage_history`와 인덱스를 삭제하며 데이터 복구가 불가능하다. 이번 준비에서는 원격 적용 여부를 확인하거나 마이그레이션을 실행하지 않았다. (`fcdcb49`)

## 변경

- 사용량 이력 API·설정·조회/저장 모듈과 cron의 이력 D1 쓰기를 제거했다. 인증·큐·동기화 등 다른 D1 쓰기까지 제거한 것은 아니다. (`fcdcb49`)
- 운영값을 env·자동 결정·보호 env 파일로 분리하고 tracked 설정에는 제품 기본값을 남겼다. PM2 이름은 package 메타데이터, 공개 키·Claude 스냅샷은 기본 경로, 큐 완료 콜백과 릴리스 확인 URL은 Worker 공개 URL에서 결정할 수 있다. 명시적 설정의 우선순위를 유지하며 서비스 env 누락은 키 이름만 보고한다. 워크스페이스 선택은 부팅 시 해석하고 저장된 선택을 보존한다. (`4b77b95`, `e94d5d6`, `c260610`, `0622702`, `2f5154a`, `3aea76b`, `d1a281c`, `d6cb5fc`, `334f4f9`)
- #226 M0: cron 단계를 격리하고 `worker.cron.tick`에 단계별 상태·소요 시간, 전체 소요 시간, D1 읽기/쓰기 행 수를 기록한다. 게이트·동기화 제어 실패도 관측한다. 24시간 쓰기량·CPU 실측이나 운영 절감 효과를 확인한 결과는 아니다. (`a77c087`, `64aa64e`)
- Claude upstream 사용량 호출을 화면 조회와 분리했다. 백그라운드 poll·동시 요청 병합·최근 결과 캐시로 반복 조회가 upstream 호출을 늘리지 않게 하고 실패 결과도 보존한다. 429 대기에 기본 10분 하한을 적용하며 `BISEO_CLAUDE_FLOOR_MS` 또는 `config/claude-oauth.json`의 `floorMs`로 설정한다. 스냅샷 만료와 현재 실패 상태를 구분한다. (`aa876cb`, `6bbafd6`)
- 사용량을 사용한 양으로 보더라도 포함·구매 잔액은 잔액으로 유지한다. Ollama는 포함·구매 잔액, Go는 허용된 창만 표시하며 기존 숨김·순서 설정을 보존한다. 캐시 안내가 카드 높이를 바꾸지 않도록 분리하고 표시 모듈·테스트를 나눴다. (`70aa956`, `2a5cfc1`, `9c87135`)
- #244: Grok 사용량 표시 이름과 리소스 기반 패널 모델 인식을 정리했다. Claude 세션 fallback은 model attachment의 `identity.marketingName`만 사용한다. Meta/xAI 아이콘을 추가하고 DeepSeek/Ollama·Claude/AGY·GPT/Go의 모델 아이콘을 보존한다. 빌드된 서버에도 모델 설정 리소스를 복사한다. (`845e136`, `46a8be5`)

## 발행·운영 범위

로컬 릴리스 준비이며 push·main 병합·태그·정식 릴리스 발행·배포·PM2 재시작·원격 D1 마이그레이션은 하지 않았다. 체크리스트의 배포 명령 `pnpm release:all`과 운영 버전 대조는 승인 범위 밖이므로 실행하지 않았다. 운영 화면 버전·인증된 사용량 회복·보호 env 파일 준비 여부·M0 장기 관측 결과는 확인하지 않았다.
