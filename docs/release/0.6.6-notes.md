# v0.6.6 릴리스 노트 (초안)

v0.6.5 태그 이후 준비 기준 `b4ad1cb`까지 병합 2건과 일반 커밋 3건을 대조했다. 근거 명령은 `git log --merges v0.6.5..HEAD`와 `git log --no-merges v0.6.5..HEAD`다. PR 번호가 없는 변경은 커밋으로 표시한다. 이번 준비 커밋은 버전·문서만 바꾼다.

## 변경

- Claude 백오프가 진행 중일 때 더 긴 Retry-After를 받으면 기존 종료 시각을 연장한다. 짧은 값으로 줄이지 않으며 추가 대기는 현재 시점부터 설정된 `maxMs`까지만 반영한다. 기존 백오프 중 실패 횟수는 늘리지 않는다. (`e3c04e3`)
- agy의 같은 quota 풀 안에서 weekly·5h 버킷을 창별로 요약한다. 서로 다른 창의 잔여율을 하나의 최솟값으로 섞지 않는다. 식별자에 `week`가 없는 모델 버킷을 5h로 분류하는 가정과 기존 #231 관측 근거·API 변경 시 수정 조건을 [운영 문서](../ops/current-operations.md)에 기록했다. 이번 준비에서 운영 API를 재측정한 결과는 아니다. (`631b885`)
- DNS 회귀 검사의 단언을 보강했다. 외부 reverse 조회가 DNS 구현에 도달하기 전에 종료하는지 종료 코드·신호·출력으로 확인하고, 콜백·Promise API 및 Resolver의 reverse·resolve 계열과 lookupService 래핑을 검사한다. 테스트 보강이며 OS 수준 네트워크 격리를 추가한 것은 아니다. (`2a8b733`)

## 로컬 검증

- net guard를 켠 전체 테스트 1053/1053·27 suites, 실패·취소·skip·todo 0이다.
- 서버·클라이언트 빌드를 통과했다. 클라이언트 빌드에는 500 kB 초과 청크 경고가 있다.
- `package.json`의 `0.6.6`, README·개발·현행 운영 문서의 준비 기준, 로컬 클라이언트 번들의 앱 버전 표식 `app-version:0.6.6`을 대조했다. 운영 버전 확인 결과는 아니다.

## 발행·운영 범위

이 노트는 로컬 릴리스 준비 기록이다. main 병합·push·태그·정식 릴리스 발행·배포·재시작은 포함하지 않는다. 체크리스트의 배포와 운영 버전 대조는 이번 승인 범위 밖이라 실행하지 않는다. 운영 화면 버전·Argon 주간 표시·인증된 사용량 회복은 확인하지 않았다.
