# v0.6.5 릴리스 노트 (초안)

v0.6.4 태그 이후 준비 기준 `2380e88`까지 병합 2건과 일반 커밋 4건을 대조했다. 근거 명령은 `git log --merges v0.6.4..HEAD`와 `git log --no-merges v0.6.4..HEAD`다. PR 번호가 없는 변경은 커밋으로 표시한다. 이번 준비 커밋은 버전·문서만 바꾼다.

## 변경

- Claude 스냅샷 경로가 없거나 설정을 읽을 수 없으면 `claude.snapshot.disabled` 경고를 프로세스당 한 번 남긴다. 경로가 없는 동안 디스크 읽기·쓰기를 건너뛰며, 이후 유효한 경로가 있으면 다시 사용할 수 있다. (`69869ea`)
- 자동 라벨 처리 한 회차에서 tab ID별 조회 Promise를 캐시해 같은 tab의 중복 조회를 줄인다. 다음 회차에는 다시 조회하며, 기존 이름 보호·조회 실패 처리·이름 변경 순서·단일 pane tab 조건은 유지한다. (#229 P2, `dc63842`)
- 테스트 net guard가 Node.js DNS의 `lookup`·`resolve*`·`reverse` 호출도 검사한다. 콜백·Promise API와 Resolver 인스턴스에서 외부 호스트 DNS 조회를 차단한다. 빈 호스트와 `localhost.`는 허용한다. (`319b008`, `c27b19c`)

사용자 동작 변화는 없다. 기존 스냅샷 비저장 상태를 경고로 드러내고 자동 라벨 조회 비용과 테스트 격리를 보강하며, 새 사용자 기능이나 운영 설정 변경은 포함하지 않는다. 테스트 net guard는 JavaScript API 검사이며 OS 수준의 네트워크 격리는 아니다.

## 로컬 검증

- DNS 차단을 포함한 net guard를 켠 전체 테스트 1050/1050·27 suites, 실패·취소·skip·todo 0이다. 외부 DNS·네트워크 접근으로 인한 실패는 없었다.
- 서버·클라이언트 빌드를 통과했다. 클라이언트 빌드에는 500 kB 초과 청크 경고가 있다.
- `package.json`은 `0.6.5`이며 README·개발·현행 운영 문서의 준비 기준도 일치한다. 로컬 클라이언트 번들의 앱 버전 표식 `app-version:0.6.5`도 대조했다. 운영 버전 확인 결과는 아니다.

## 발행·운영 범위

이 노트는 로컬 릴리스 준비 기록이다. main 병합·push·태그·정식 릴리스 발행·배포·재시작은 포함하지 않는다. 체크리스트의 배포와 운영 버전 대조는 이번 승인 범위 밖이라 실행하지 않았다. 운영 화면 버전·Argon 주간 표시·인증된 사용량 회복은 확인하지 않았다.
