# v0.6.0 릴리스 노트 (초안)

## 변경
- #227: Grok 사용량은 OpenCode DB의 access 토큰만 읽고 refresh하지 않는다. 실패를 auth·transient·schema로 나눠 표시하며, 주간 기간은 `w`로 표시한다. 사용량 새로고침 버튼을 추가했다(쿨다운은 `web/usage-config.json`).
- #228: Claude 사용량 429 백오프는 `retry-after`를 반영하되 15분이 상한이다(`config/claude-oauth.json`). 직전 성공값을 `data/claude-usage.json`에 영속 저장하고, 창의 `resetsAt`까지 stale로 표시한다. 테스트 mock도 정리했다.
- #229: 기존 agent name·tab label이 있는 pane은 자동 라벨러가 덮어쓰지 않는다.
- #231: agy Gemini 사용량 갱신 수정. 기본 호스트가 `daily-cloudcode-pa.googleapis.com`이다.

## 제거
- `BISEO_GROK_REFRESH_URL` 환경 변수.
