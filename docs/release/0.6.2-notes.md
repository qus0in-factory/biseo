# v0.6.2 릴리스 노트 (초안)

v0.6.1 이후 `c6fe17a`까지의 병합 1건과 일반 커밋 4건을 대조했다. 근거 명령은 `git log --merges v0.6.1..HEAD`와 `git log --no-merges v0.6.1..HEAD`다. PR 번호가 없는 변경은 커밋으로 표시한다.

## 변경

- 사용하지 않는 `agyCliEnabled` 필드·검증기를 제거했다. 구버전 `runtime.json`에 남은 키는 무시하며, `true`여도 CLI 폴백 설정을 바꾸지 않는다. 폴백은 기본 켜짐이며 `BISEO_AGY_CLI_ENABLED=0`일 때만 꺼진다. (`2b4611d`, `bb20f4f`)
- `pnpm test`에 JS preload 네트워크 가드를 적용했다. 외부 fetch·TCP·TLS·UDP 연결을 차단하고 loopback·Unix-domain IPC는 허용한다. 차단 예외를 잡아도 테스트 프로세스는 실패한다. OS 격리가 아니며 네이티브 CLI나 preload를 제거한 자식 프로세스까지 차단하지는 않는다. (`2b142fa`, 병합 `c6fe17a`)
- 저장소 `config/runtime.json`의 `allowedWorkspaceId` 기본값을 `w1Y`로 바꿨다. 기존 `config/workspace-selection.json`의 유효한 선택이 우선하므로 이 변경만으로 운영 선택이 바뀌었다고 보지 않는다. (`21e9808`)

## 발행·운영 범위

이 노트는 로컬 릴리스 준비 기록이다. main 병합·push·태그·정식 릴리스 발행·배포·재시작은 포함하지 않는다. 운영 버전, 실제 워크스페이스 선택과 사용량 회복은 이 작업에서 검증하지 않았다.
