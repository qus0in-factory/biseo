# v0.6.8 릴리스 노트 (초안)

## 변경

- #246: 좁은 화면의 제공자 사용량 모달에서 토글과 버튼 묶음을 두 줄로 배치한다. 새로고침·제공자 설정 문구가 단어 중간에서 꺾이지 않게 하고, 기존 `sm` 이상에서는 한 줄 배치를 유지한다. 기존 디자인 토큰·리소스 문구·버튼 동작을 유지하며 컴포넌트 회귀 테스트를 추가했다. (`c637ff0`)
- 실제 컴포넌트와 빌드 CSS로 320px·375px에서 가로 넘침 없이 버튼 문구 한 줄·높이 44px을 확인했다. 인증된 전체 모달 e2e 검증은 아니다. (#246)

## 운영 이력

v0.6.7 배포 뒤 원격 D1에 `0013_drop_usage_history.sql` 적용을 마쳤다. Grok의 적용 보고에서 성공과 적용 후 `No migrations to apply`를 확인했다. 사용량 이력 테이블·인덱스 삭제는 되돌릴 수 없으며, 인증·큐·동기화 등 다른 D1 쓰기를 제거한 것은 아니다. 이번 릴리스 준비에서 마이그레이션을 다시 실행하지 않았다.

#246 조사에서 운영 Cloudflare Insights beacon이 `script-src 'self'`에 차단되는 콘솔 오류를 확인했다. 원인만 진단했으며 CSP·분석 설정은 변경하지 않았다.

## 변경 목록 대조

`git log --merges v0.6.7..HEAD`는 0건, `git log --no-merges v0.6.7..HEAD`는 `c637ff0` 1건이다. 준비 시작 HEAD는 `c637ff0`이며 위 변경을 해당 커밋과 대조했다. 이번 준비 커밋은 버전·문서만 바꾼다. D1 적용은 Git 변경이 아닌 별도 운영 이력이다.

## 로컬 검증

- `pnpm test`: 빌드 후 1096/1096·27 suites, 실패·취소·skip·todo 0.

## 발행·운영 범위

로컬 준비이며 push·main 병합·태그·정식 릴리스 발행·배포·PM2 재시작은 하지 않았다. 체크리스트의 `pnpm release:all`과 운영 버전 대조는 실행하지 않았다. 보호 env 준비 여부·인증된 운영 사용량 회복·M0 장기 관측은 이번 준비에서 확인하지 않았다.
