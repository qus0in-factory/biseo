# v0.6.1 릴리스 노트 (초안)

v0.6.0 이후 병합 커밋(`git log --merges v0.6.0..HEAD`) 4건과 test 커밋 1건 기준이다.

## 변경
- agy 모델 턴 폴백(`agy -p /usage`)은 기본 꺼짐이다. `BISEO_AGY_CLI_ENABLED=1`일 때만 켜지며, 꺼진 상태에서 Argon 주간 값은 알 수 없음으로 표시한다. (`fix/agy-no-model-fallback`)
- #231 P2: `BISEO_AGY_HOST` 끝 슬래시를 제거하고, 모델 quota 파생 버킷을 5h로 표시한다. (`fix/agy-review-p2`)
- Claude: 백오프 설정 검증과 기본값 보정, 동시 429 중복 방지를 넣었다. (`fix/usage-review-p2`)
- Grok: 제공자 stale 정책을 설정으로 분리했다. (`fix/usage-review-p2`)
- 릴리스: `pnpm release:all`(release → deploy → verify)을 추가했다. `release:verify`는 푸터의 앱 버전 표식(`app-version:<버전>`)과 비교한다. (`chore/release-verify`)
- 테스트: `usage-endpoints-agy.test.ts`를 1024자 이하로 줄였다.
