## Why

외부 브라우저 또는 REST 클라이언트가 `/health`에 접속해 HTTP **200**을 받는 것이 0.1.0의 목표다.

## What

- 스택: **Hono + pnpm + PM2**
- 로컬: `http://127.0.0.1:6543/health`
- 외부: **Tailscale Funnel HTTPS 443 → 로컬 6543**
- 인증: **없음**. API key·JWT·PASETO·워커 API 등은 다음 단계이며 현재 구현하지 않는다.
- 응답: 내부 정보가 없는 최소 health 응답.

## How

서버 → PM2 → Funnel → 외부 HTTP 200 확인 순서로 진행한다. 각 하위 이슈는 주책임을 나타내는 평면 라벨 하나와 `0.1.0` 마일스톤을 가진다. 우선도·영향도는 본문 필드로 기록하고 선행 의존성을 먼저 따른다.

외부에서 인증 없이 HTTP 200을 받은 결과를 확인한 경우에만 완료한다. 이 이슈의 계획 정리 자체는 실제 서비스 동작 확인을 뜻하지 않는다.

인증을 요구했던 이전 초안은 사용자의 최신 지시로 보류되었다. 상세 목표와 다음 버전은 추후 정한다.
